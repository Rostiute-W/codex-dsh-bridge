Codex 交接，DSH 原生聊天执行

直接在 DSH 的对话中查看过程、补充要求和引导方向；Bridge 负责验证与审查结果回传。

  1. 1

    连接 DSH 原生对话

    新任务自动新建并打开 DSH 聊天，使用运行设置中的模型选择。

    先从托盘完整退出 DSH，再点击安装并重新打开。会覆盖本软件旧版只读观察插件的实现。任务消息和权限都在 DSH 处理；聊天继续后必须重新验证，才能审查提交。

  2. 2

    注册 MCP 与 Skill

    正在检查 Codex 配置

    相同配置会识别为已注册，重复点击不会重复安装。接入完成后重载 Codex MCP；收到连接握手或工具调用后显示最近调用时间。

  3. 3

    重启 DSH，重载 Codex MCP

    连接插件只有在 DSH 重启后才会加载：从托盘完整退出 DSH 再重新打开。然后在 Codex 中重载 MCP 或重开聊天，让新的工具定义生效。Bridge 不会替你结束 DSH 进程。

  4. 4

    开始一个任务

    $codex-dsh-bridge 请分析这个项目中的任务，明确方案后交给 DSH 执行，完成后审查代码。

    Codex 会检查 Git 基准和工作区状态，并生成带有验收要求的交接内容。
